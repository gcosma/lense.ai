# Lense.ai website

Static website for **Lense.ai** — thematic and human factors analysis of incident and investigation reports, developed at Loughborough University.

## Pages

| File | Page |
|------|------|
| `index.html` | Main site |
| `lense-user-guide-complete.html` | User guide (page-by-page guide to the workspace) |
| `pfd-archive-overview.html` | The Prevention of Future Deaths reports archive: an overview |

## Hosting

The site is deployed to GitHub Pages automatically by the workflow in `.github/workflows/deploy-pages.yml` on every push to the default branch.

Once the first deployment has run, the site is available at:

**https://gcosma.github.io/lense.ai/**

To update the site, edit the HTML files and push — the workflow redeploys automatically.
